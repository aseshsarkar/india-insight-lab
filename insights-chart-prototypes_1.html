Flow, relationship and distribution charts for the Insights tab

Three chart types the current Insights feed doesn't have yet, each built to match the existing card system (same border, badge and footer conventions as the indicator cards already on the site) and rendered as plain inline SVG — no charting library, consistent with how the rest of the app draws its waterfall, dimension and score-history charts.

This revision replaces guessed numbers with real ones: I opened indiainsightlab.com in a browser and read each indicator's actual chart tab before claiming it was "ready." Several indicators I'd assumed were state-by-state turned out to be national-only on the Chart tab (lfprPanels, literacy, povertyLines, mpce, sexRatioBirth among them) — those are marked below as not fitting, honestly, rather than mocked up anyway. Only two indicators below now carry real, verified figures; the chord still stands on illustrative numbers because the underlying state-pair data doesn't exist yet in the catalog at all.

Today this indicator (migration) renders as four "ranked bars" on the live site. A Sankey reads the same four numbers as one shape: rural-to-rural — mostly marriage-related moves by women — is the thickest stream, and rural-to-urban labour migration, the stream most associated with India's growth story, is visibly the second-largest, not the biggest. These figures (54% / 20% / 18% / 8%) are the exact numbers currently live on indiainsightlab.com — checked in-browser, not estimated.

The Employment & labour topic description already promises "migration corridors" — nothing on the site delivers on that yet. A chord is the right shape for it, but it needs a state × state origin-destination matrix, which isn't in the current dataset (only national stream shares are); ribbon widths and opacity here are illustrative, standing in for that matrix. Colour: the 11 hues (one per node, sources and hubs alike) are sampled directly from the investor Sankey you shared — the same dusty blue, brick red, sage green, gold, teal, brown and orange family, not the brighter flat-UI palette this started with. This departs from the site's muted 6-colour topic-accent palette, which isn't built for 11-way identification. Every ribbon is also directly labelled at both ends, so identification never depends on colour alone.

Correction from the first draft: neither of these indicators has more than one year of state-level data on the Chart tab, so this is not the "distribution sliding over years" story I originally mocked up for lfprPanels — that indicator turned out to be 4 national metrics, not 20 states, and has been dropped from this page. What a ridgeline still does well here, even for one year: a ranked bar list of 28–33 states makes you scroll and read; this shape shows the whole distribution at once — where Bihar and Jharkhand sit as a real tail on poverty, where Kerala sits as a real outlier on literacy. Every value plotted is the exact number currently live on the site.

Everything above is hand-rolled SVG driven by plain JS objects (a sankey(), a chord(), and one ridgeline() function drawing both real state distributions) — no D3 or chart library, so it drops into the existing template system the same way the I3 waterfall and score-history charts already do. The Sankey and ridgeline reuse the site's own topic accents (rural/Population green, urban/Employment ochre); the chord remains the one section running on illustrative numbers, and still introduces its own 11-colour set — one saturated hue per node, sources and hubs alike — matching the bold, fully-coloured look of the reference chords you shared, rather than the site's muted 6-colour topic palette.

Two of these three are ready to wire into the live dataset as-is: the migration Sankey (54/20/18/8, checked live) and the poverty/literacy ridgeline (28 and 33 real state values, checked live). The chord is the one still waiting — it needs a real state-to-state migration corridor matrix, which Census D-series has at a coarser resolution than shown here, and isn't in the indicator catalog yet. Once you tell me where that matrix should come from, the chord can ship with real numbers too; until then it stays labelled "illustrative."
